I de fleste virksomheter er e-post den viktigste og samtidig den mest angrepne kommunikasjonskanalen, og uten ryddige identiteter fungerer verken e-postruting eller tildeling av tilganger. Denne huben samler praktisk kunnskap fra mer enn 14 års drift av store e-postmiljøer: SMTP og e-postflyt, krypteringsgatewayer som SEPPmail og Totemomail, HIN-e-postgatewayen i det sveitsiske helsevesenet, Exchange og Microsoft 365 i hybridscenarioer samt Active Directory, LDAP og Microsoft Entra ID som fundamentet bak det hele. I tillegg finnes gratis verktøy som lar deg kontrollere ditt eget domene og din e-postkonfigurasjon direkte i nettleseren.
